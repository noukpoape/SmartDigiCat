Avant d'installer

Ce qui sera installé

  • Un dossier SmartDigiCat dans le dossier Applications, contenant :
    • SmartDigiCat : le logiciel (tous ses fichiers sont regroupés et masqués à l'intérieur) ;
    • Désinstaller SmartDigiCat : pour le supprimer de ce Mac.

Désinstallation

Ouvrez Applications > SmartDigiCat et double-cliquez sur Désinstaller SmartDigiCat. Vos projets et vos données ne sont jamais supprimés.

Mise à jour

Pour passer à une nouvelle version, lancez simplement son installeur : l'ancienne version est remplacée.

Manuel

Le manuel d'utilisation s'ouvre avec le bouton Help du logiciel.
