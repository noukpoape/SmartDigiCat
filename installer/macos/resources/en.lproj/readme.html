Before installing

What will be installed

  • A SmartDigiCat folder in Applications, containing:
    • SmartDigiCat: the software (all its files are bundled and hidden inside it);
    • Désinstaller SmartDigiCat: the uninstaller.

Uninstalling

Open Applications > SmartDigiCat and double-click Désinstaller SmartDigiCat. Your projects and data are never deleted.

Updating

To move to a new version, just run its installer: the previous version is replaced.

Manual

The user manual opens with the Help button in the software.
