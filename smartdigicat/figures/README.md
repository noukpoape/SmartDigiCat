# Icons and user manual

The application loads its icons and its user manual from this folder
(see `my_path()` in `smartdigicat/app.py`).

## Icons (PNG)

Icons used by the interface:

- **Top bar**: `new_p.png`, `open_p.png`, `save_p.png`, `undo_p.png`, `redo_p.png`,
  `import_p.png`, `settings_p-32.png`, `results_p.png`, `model_p.png`, `run_p.png`,
  `log_p.png`, `help_p.png`, `web_p.png`
- **Left bar**: `new_analysis.png`, `delete.png`, `Rename_model.png`, `settings.png`,
  `restore.png`, `arret.png`, `picture_save.png`, `csv_import.png`, `langue.png`
- **Panels**: `icon.png` (home logo), `save_config_model.png`, `Model_edit.png`,
  `New_model.png`, `Delet_model.png`, `apercu_p.png`, `save_graph_p.png`,
  `Export_data_p.png`, `Export_data_pred.png`, `Edit_data_p.png`, `View_pred.png`,
  `show_all.png`, `import_data_pred.png`, `scatter_p.png`, `affiche_data_p.png`,
  `Box_plot_p.png`, `descriptive_p.png`, `image_hist_p.png`, `plot3d_p.png`,
  `optimization.png`, `run_opt.png`, `barre_p.png`, `view_stat.png`,
  `corr_plot.png`, `other_analysis_p.png`

The other PNG files in this folder (`Button_*.png`, `centralelille.png`,
`zoom.png`, ...) are not used by the current version; they are kept for
earlier and possible future versions of the interface.
